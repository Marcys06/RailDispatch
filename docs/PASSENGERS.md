# PASSENGERS

## Cel

System pasażerski dostarcza podstawowego zapotrzebowania na przewozy.

## Generowanie

Pasażerowie są generowani proceduralnie.

Zapotrzebowanie zmienia się okresowo.

W becie aktualizacja następuje co 60 minut czasu symulacji.

## Stacje

Każda stacja może posiadać zapotrzebowanie pasażerskie.

Zapotrzebowanie może zależeć od lokalizacji i parametrów stacji.

## Przewóz

Pasażerowie korzystają z dostępnych usług.

Obsługa pasażerów odbywa się podczas postoju pociągu.

## Towary

System pasażerski jest projektowany z myślą o późniejszym dodaniu różnych rodzajów towarów.

Towary nie są wymagane jako pełna funkcja wersji beta.

Architektura powinna jednak umożliwiać ich późniejsze dodanie.
