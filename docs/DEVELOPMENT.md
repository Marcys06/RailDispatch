# DEVELOPMENT

## Środowisko

Podstawowym środowiskiem programistycznym jest Visual Studio.

GitHub jest repozytorium projektu.

## Branching

develop jest głównym branchem rozwojowym.

master zawiera stabilne wersje.

Większe funkcje powinny być rozwijane na osobnych branchach.

## Issues

Issues służą do śledzenia:

- funkcji
- błędów
- zadań technicznych
- zmian dokumentacji

## Milestones

Wersjonowanie korzysta ze schematu 0.x.y.

x mieści się w zakresie 0–9.

y mieści się w zakresie 0–8.

y przyjmuje wyłącznie wartości parzyste.

## Pull Request

Pull Request powinien zawierać opis zmiany.

Pull Request powinien wskazywać powiązane Issue, jeżeli takie istnieje.

## Changelog

Istotne zmiany są zapisywane w CHANGELOG.md w katalogu głównym repozytorium.

## Dokumentacja

Zmiany mechaniki powinny aktualizować odpowiedni dokument w docs/.

Zmiany architektury powinny aktualizować ARCHITECTURE.md.

Zmiany modelu danych powinny aktualizować DATA_MODEL.md.
