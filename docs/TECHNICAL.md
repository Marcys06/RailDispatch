# TECHNICAL

## Platforma

Projekt jest tworzony w Visual Studio.

Projekt korzysta z technologii dostępnych w ekosystemie .NET.

Projekt nie korzysta z zewnętrznego silnika gier.

## Repozytorium

Kod jest przechowywany w publicznym repozytorium GitHub.

Branch develop służy do bieżącego rozwoju.

Branch master służy do stabilnych wersji.

## Mapa

Maksymalny rozmiar mapy wynosi 16384 × 16384 pól.

Mniejsza mapa jest dozwolona.

## Symulacja

Tick symulacji wynosi 20 ms.

Skala czasu wynosi 60:1.

## Wydajność

System powinien ograniczać obliczenia do elementów wymagających aktualizacji.

Renderowanie powinno być niezależne od częstotliwości symulacji.

## Dane

Format zapisu powinien być wersjonowany.

Zmiana modelu danych nie powinna uniemożliwiać późniejszej migracji starszych zapisów.

## Beta

Beta jest działającym prototypem.

Elementy przewidziane na przyszłość powinny posiadać podstawy architektoniczne już w becie.
