# SCHEDULES

## Cel

System rozkładów służy do planowania ruchu kolejowego.

## Usługi

Usługa jest tworzona jako pierwszy element planowania.

Tabor jest przypisywany do istniejącej usługi dopiero później.

## Trasa

Użytkownik wybiera całą trasę usługi.

System automatycznie analizuje trasę.

## Rozkład

Rozkład określa:

- kolejność stacji
- czasy przejazdu
- postoje
- wymagane przyjazdy
- wymagane odjazdy

## Stacje

Pociąg musi wykonać postój na stacji zgodnie z rozkładem.

## Priorytet

Usługa posiada tag priorytetu.

Rozbudowany system priorytetów pozostaje przeznaczony na przyszłe wersje.

## Automatyzacja

System automatycznie wylicza czasy oraz sprawdza wykonalność planu.

System nie podejmuje za użytkownika decyzji dyspozytorskich.

## Statystyki

System rejestruje podstawowe statystyki realizacji usług.

Statystyki obejmują między innymi opóźnienia i wykonanie rozkładu.
