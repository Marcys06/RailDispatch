# UI

## Cel

Interfejs jest minimalistyczny.

Mapa jest głównym elementem interfejsu.

## Mapa

Większość operacji wykonywana jest bezpośrednio na mapie.

Użytkownik może budować infrastrukturę bez przechodzenia przez rozbudowane menu.

## Narzędzia

Interfejs zapewnia narzędzia do:

- budowy torów
- budowy rozjazdów
- stawiania semaforów
- budowy stacji
- tworzenia pociągów
- sprzęgania pojazdów
- rozdzielania składów
- tworzenia usług
- tworzenia rozkładów

## Pociąg

Interfejs pokazuje podstawowe informacje o pociągu:

- prędkość
- Vmax
- masa
- długość
- kierunek
- stan

## Dyspozytura

Interfejs pozwala użytkownikowi wybrać pełną trasę.

System pokazuje konflikty i ograniczenia.

## Błędy

Interfejs informuje użytkownika o problemach z ruchem.

Przykładem jest wykolejenie pociągu.

## Zasada

Minimalizm interfejsu jest ważniejszy od liczby dostępnych paneli.
